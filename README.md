# 一碗面 · Noodles

记录做饭的过程，也照顾生活里的小物件。

一碗面是一款使用 Flutter 开发的本地生活记录应用：把喜欢的菜记下来，为每次调整保留一个版本；纠结吃什么时交给「饭否」；用「万物」整理物品、查看保质期；在「记账」中记录和查看日常收支。无需注册账号，核心功能离线可用。

## 功能

### 菜谱：把拿手菜慢慢打磨出来

- 记录菜谱名称、分类和简介，搜索名称、简介或分类。
- 按最近更新、最近创建或名称排序。
- 为一道菜创建、编辑、复制多个烹饪版本，分别记录食材、步骤、评分、成品反馈和下次改进。
- 每个版本最多保存 5 张成品照片，支持拍照或从相册选择。
- 标记最佳版本，对比两个版本的用料、步骤、照片和复盘记录。
- 在详情页收藏菜谱；在「我的」中管理分类，点选分类可返回筛选后的菜谱列表。

### 饭否：今天吃点什么？

- 跳转到分类选择页，搜索并多选参与抽取的分类；不选分类表示「都可以」。
- 设置这顿做几道，从已有菜谱中随机选择，同一桌内不会重复。
- 锁定想保留的菜，再点「换一桌」替换其他菜，并优先选择上次没出现的菜。
- 点击抽中的菜谱即可查看做法。

### 万物：让物品和保质期有迹可循

- 添加、编辑、复制和删除物品，记录分类、位置、数量、生产日期、购买信息和备注。
- 直接填写到期日期，或根据生产日期及天／周／月／年的保存时长计算。
- 每件物品最多保存 5 张图片。
- 按名称、分类或位置搜索，按分类及到期区间筛选。
- 查看已过期和不同天数内到期的物品数量，按最近到期、最近更新或最近创建排序。
- 在「我的」中维护物品分类、调整到期区间。

到期区间是累计统计：例如「15 天内到期」包含「7 天内到期」的物品，但不包含已过期物品。当前到期提示通过应用内统计和筛选展示。

### 记账：记录日常收支

- 记录支出或收入的金额、分类、日期和备注，并可编辑或删除记录。
- 按日期范围查看总支出、总收入、分类统计和收支明细。
- 维护支出与收入分类；删除分类不会删除已有记录。

## 技术与目录

应用使用 Flutter / Material 3 构建界面，Riverpod 管理状态，`sqflite` 保存本地数据，`image_picker` 处理拍照和图片选择。Android 通过 MethodChannel 调用系统文件选择器完成万物数据及菜谱 JSON 导入、导出。

```text
lib/
├── main.dart                  # 应用入口
├── app.dart                   # MaterialApp 配置
├── core/
│   ├── database/              # SQLite 仓储、数据导入导出
│   └── theme/                 # 颜色与主题
├── features/
│   ├── recipes/               # 菜谱列表、新建与详情
│   ├── versions/              # 烹饪版本编辑入口
│   ├── comparison/            # 版本对比
│   ├── fanfou/                # 随机选菜与分类多选
│   ├── inventory/             # 物品与物品分类
│   ├── accounting/            # 收支记录、分类与统计
│   └── profile/               # 分类、到期区间和数据迁移设置
├── models/                    # 数据模型、输入解析和抽菜逻辑
└── providers/                 # Riverpod 数据提供器
test/                          # 单元／界面测试与验证记录
android/app/src/main/kotlin/    # Android 系统文件选择实现
```

## 运行项目

当前主要面向 Android 开发和调试。仓库保留了 Flutter 生成的其他平台目录，但不代表这些平台已经完成适配

### 环境

- Flutter stable；当前开发环境为 Flutter **3.47.5**、Dart **3.13.4**。
- Dart SDK 需满足 `pubspec.yaml` 中的 `^3.13.4` 约束。
- Android SDK、JDK 17，以及开启 USB 调试的 Android 手机或模拟器。

在克隆后的项目根目录运行：

```sh
flutter doctor
flutter pub get
flutter devices
flutter run
```

连接多台设备时，使用 `flutter run -d <设备ID>` 指定目标。应用不需要配置后端服务或 API Key。

###  构建 APK

```sh
# 测试包（可与正式版同时安装）
flutter build apk --flavor qa --debug

# 正式版 Release 包
flutter build apk --flavor prod --release
```

APK 产物位于 `build/app/outputs/flutter-apk/`：测试包为 `app-qa-debug.apk`，正式版为 `app-prod-release.apk`。测试包使用独立包名 `com.byone421.noodles.test`，不会覆盖正式版。
